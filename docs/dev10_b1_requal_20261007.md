## Debugging conclusion

The prior parser bug is fixed: truncated responses are now explicitly rejected
as incomplete top-level JSON instead of being misparsed as nested `video` data
and mislabeled as an empty `objects` list. Raising the cap to 2400 did not
prevent three long outputs from truncating. Four complete real-case outputs
still contain duplicate names, and B1 misses motion in the valid `B_02` scene.
These are model-output/protocol limitations, not compiler defects.

**Qualification: FAIL (3/10 checker-valid; 2/10 scorer-complete).** Keep B1
unqualified. Do not claim a reliable B1-vs-B2 comparison or start deferred
follow-on ideas. Raw generations, worlds, official reward details, and logs
remain on the experiment host; none are uploaded here.
